Over the past couple of months, I've been developing this project as a fun experiment in my spare time. It has been well known since the Push 3 Standalone was launched that it runs a customized Linux operating system and that it can be accessed via SSH. 

Push Hack began as a research project aimed at understanding what could potentially be developed and added to Push Standalone; then, with the support of AI assisted coding tools, it quickly evolved into something much more complex.

This project was inspired by the work done in the [Move Anything](https://github.com/bobbydigitales/move-anything) and [Schwung](https://github.com/charlesvestal/schwung) projects for Ableton Move.

> Before we dive deeper into the project it's important to say that **Push Hack is NOT approved, endorsed or supported by Ableton**. If you decice to install it on your device, you're using it at your own risk.
{: .warning }
