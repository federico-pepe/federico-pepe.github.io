One of the best feature introduced with the latest update of Logic Pro X 10.1 is the new GUI for the built-in compressor plug-in. With this new interface is much easier to access the different emulations of circuit type that were a «hidden secret» for many users&nbsp;in&nbsp;the previous versions.

## Compressors' Circuit Types
Some hardware compressor had become standards not just because of their ability to compress audio but also for the tonal quality and the side-effects added&nbsp;to the signal. With the advent of DAWs and software plug-ins developers had to emulate this effects, especially&nbsp;with&nbsp;the compressors. These are the&nbsp;main classes of circuit types used to build hardware compressor:
- [VCA: Voltage Control Amplifier](http://en.wikipedia.org/wiki/Variable-gain_amplifier "VCA: Voltage Control Amplifier on Wikipedia")
- [FET: Field-Effect Transistor](http://en.wikipedia.org/wiki/Field-effect_transistor "Field-effect Transistor on Wikipedia")
- [Opto: Optical Compressor](http://en.wikipedia.org/wiki/Dynamic_range_compression#Design "Optical Compressor on Wikipedia")

Before the introduction of Logic Pro X 10.1 we just had a small dropdown menu to choose the circuit type. Many users ignored it and kept using the _Platinum_&nbsp;which was (and still is) the default&nbsp;choice. This circuit is built by Logic's developers and although it is very powerful, it doesn't have&nbsp;any sound quality nor emulates any renowned compressor. If you're one of that kind of users, please keep reading. ![Logic Pro built-in compressor](/assets/uploads/2015/02/Logic_Pro_Compressor.png) The circuit type dropdown menu in Logic's compressor. The other circuit types were in fact emulations but nobody could name exactly all of them (try a quick search on google to find the guesses), until now. With the new GUI, developers helped us a lot:&nbsp;we can name&nbsp;exactly every emulation thanks to the colours of the panel and the design of the knobs. Now you're probably asking yourself: "Why is this so important"? Because there are many books, articles and tutorials about which compressor is best for vocals, guitars, drums and any other source. If you learn which&nbsp;circuit type you're using, you'll become a better engineer by using Logic's built-in compressor (and you'll save a lot of money on third-party plugins).
## Platinum Digital
[![Circuit Type: Platinum Digital](/assets/uploads/2015/02/Fig.1_-_Logic_Pro_X_10.1_Platinum_Compressor-1024x805.png)](/assets/uploads/2015/02/Fig.1_-_Logic_Pro_X_10.1_Platinum_Compressor.png) As said before, this circuit is Logic's own design and it's the default setting when we load a compressor in our channel strip. It can be very helpful in some situation because of its transparent sound.
## Studio VCA
[![Logic Pro X Studio VCA Compressor](/assets/uploads/2015/02/Fig.2_-_Logic_Pro_X_10.1_Studio_VCA_Compressor-1024x805.png)](/assets/uploads/2015/02/Fig.2_-_Logic_Pro_X_10.1_Studio_VCA_Compressor.png) &nbsp; This circuit type has been introduced with this latest update so it is completely new. The **Studio VCA** is an emulation of the&nbsp; **Focusrite Red 3 Dual Compressor and Limiter** (you can find the user manual [here](http://uk.focusrite.com/sites/default/files/downloads/7054/redrangemanual3.pdf "Focusrite Red 3 Dual Compressor User Manual")). As the name implies, the original hardware version can be used as a stereo or dual mono compressor and has its own limiter module which can ben enabled separately. The controls are: _ratio_ (1.5:1, 2:1, 3:1, 5:1, 7:1 or 10:1), _threshold_ (the original range is between -24dB to +12dB),&nbsp;_attack_ (fast to slow),&nbsp;_release_ (from 0.1 to 4 seconds) and&nbsp;_make-up gain_. Logic Pro X allow us to user different values for all this controls but I strongly suggest you to stick with the original values: anything is easier to use when you have less choices.
## Studio FET
[![Logic Pro X Studio FET Compressor](/assets/uploads/2015/02/Fig.3_-_Logic_Pro_X_10.1_Studio_FET_Compressor-1024x805.png)](/assets/uploads/2015/02/Fig.3_-_Logic_Pro_X_10.1_Studio_FET_Compressor.png) &nbsp; The&nbsp; **Studio FET** circuit type emulates the&nbsp; **Universal Audio 1176&nbsp;** which is [still available](http://www.uaudio.com/hardware/compressors/1176LN.html "Universal Audio 1176") on the market in its hardware version.&nbsp;The controllers available on the original compressor are:&nbsp;_input_,&nbsp;_output, attack_ (from 20 to 800 microseconds),&nbsp;_release&nbsp;_(from 50 to 1100 milliseconds),&nbsp;_ratio_ (4:1, 8:1, 12:1 or 20:1). Unfortunately on Logic's version of this compressor is not possibile to emulate the "All-Button" mode (all the ratio buttons pressed simultaneously)&nbsp;which many engineers love for its pumping sound.
## Classic VCA
[![Logic Pro X - Classic VCA Compressor](/assets/uploads/2015/02/Fig.4_-_Logic_Pro_X_10.1_Classic_VCA_Compressor-1024x805.png)](/assets/uploads/2015/02/Fig.4_-_Logic_Pro_X_10.1_Classic_VCA_Compressor.png) &nbsp; The&nbsp; **Classic VCA** &nbsp;duplicates the discontinued&nbsp; **DBX 160 compressor/limiter&nbsp;** (the original user manual can be [downloaded here](http://rdn.harmanpro.com/product_documents/documents/604_1324058562/160-161%20Owners%20Manual_original.pdf "DBX 160 User Manual")). The controls on the original hardware are:&nbsp;_threshold&nbsp;_(from 10mV to 3 volts),&nbsp;_ratio_&nbsp;(from 1:1 to 120:1) and _output gain&nbsp;_(from -20dB to +20dB).&nbsp;Since the attack and release parameters are not available on the hardware, those knobs aren't available on the plugin either.
## Vintage VCA
[![Logic Pro X - Vintage VCA Compressor](/assets/uploads/2015/02/Fig.5_-_Logic_Pro_X_10.1_Vintage_VCA_Compressor-1024x805.png)](/assets/uploads/2015/02/Fig.5_-_Logic_Pro_X_10.1_Vintage_VCA_Compressor.png) &nbsp; The&nbsp; **Vintage VCA_&nbsp;_** is the emulation of the&nbsp; **SSL G Bus compressor&nbsp;** which can still be found on SSL's desks&nbsp;as well as in other formats such as [500 module](http://www.solid-state-logic.com/music/Xlogic%20500%20series%20modules/bus_comp.asp "SSL Bus Compressor 500")&nbsp;or [native plugin](http://www.solid-state-logic.com/music/duende%20native/bus%20compressor/ "SSL G Bus Compressor Native Plugin"). The original controls are:&nbsp;_threshold_ (between -20dB and +20dB),&nbsp;_ratio_ (2:1, 4:1 or 20:1),&nbsp;_attack&nbsp;_(from 0.1 to 30 ms),&nbsp;_release_ (from 0.1 to 1.2 seconds or AUTO) and&nbsp;_make-up gain_.
## Vintage FET
[![Logic Pro X - Vintage FET Compressor](/assets/uploads/2015/02/Fig.6_-_Logic_Pro_X_10.1_Vintage_FET_Compressor-1024x805.png)](/assets/uploads/2015/02/Fig.6_-_Logic_Pro_X_10.1_Vintage_FET_Compressor.png) &nbsp; **Vintage FET&nbsp;** is the emulation of the&nbsp; **UREI 1176 Silver Face**. Which&nbsp;had different components compared to the&nbsp;_Universal Audio 1176&nbsp;_but the same controls. As above, we can't access the "all-button" mode in Logic's version.
## Vintage Opto
[![Logic Pro X - Opto Compressor](/assets/uploads/2015/02/Fig.7_-_Logic_Pro_X_10.1_Vintage_Opto_Compressor-1024x805.png)](/assets/uploads/2015/02/Fig.7_-_Logic_Pro_X_10.1_Vintage_Opto_Compressor.png) &nbsp; Last but not least the&nbsp; **Vintage Opto&nbsp;** which is the copy of the&nbsp; **Teletronix LA2A** , a must-have compressor for any engineer. **&nbsp;** The original hardware version of this compressor has only two control knobs:&nbsp;_gain&nbsp;_and _peak reduction__._&nbsp;As you can read on the [user manual](http://www.uaudio.com/media/assetlibrary/l/a/la-2a_manual.pdf "Teletronix LA2A User Manual"), the&nbsp;_attack_&nbsp;is very fast&nbsp;and the&nbsp;_release&nbsp;_time is&nbsp;approximately 0.06 seconds for 50% release, 0.5 to 5 seconds for complete release depending upon the amount of previous reduction.&nbsp;The peak reduction knob controls both the threshold and the amount of compression.
